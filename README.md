# advance-email-collector
Real-time email scraper with FastAPI backend &amp; React frontend. Streams emails live as pages are scanned. Features: depth control, deduplication, CSV/TXT export, dark UI.
# Advance Email Collector — Swift Tool

## Backend chalayein:
```
cd backend
"C:\ProgramData\anaconda3\python.exe" -m pip install -r requirements.txt
"C:\ProgramData\anaconda3\python.exe" -m uvicorn main:app --reload
```

## Frontend chalayein (naye terminal mein):
```
cd frontend/my-app
copy "..\..\frontend\src\App.jsx" "src\App.jsx"
copy "..\..\frontend\src\App.css" "src\App.css"
npm start
```

## Features:
- Real-time streaming — emails turant dikhti hain
- Live page counter
- Stop/Start control
- Max pages limit
- CSV + TXT export
- Dark professional UI
